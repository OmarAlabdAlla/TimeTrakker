## ✨ Features

- 📊 **Track Work Sessions** - Monitor your productivity with accurate session tracking

## 🚀 Installation

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)

### Steps

1. **Clone the repository:**
```bash
git clone https://github.com/OmarAlabdAlla/TimeTrakker.git
cd TimeTrakker
```

2. **Install dependencies:**
```bash
pip install -r requirements.txt
```

3. **Run the application:**
```bash
python time_tracker.py
```

## 💡 Usage

```bash
# Start the time tracker
python time_tracker.py

# Your work sessions will be automatically tracked and stored
```
