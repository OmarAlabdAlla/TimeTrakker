\# TimeTrakker



TimeTrakker is a lightweight Python productivity application designed to help users track work sessions and manage their time efficiently.



\## Features



\- Track work sessions

\- Store session data locally

\- SQLite database integration

\- Lightweight and simple design

\- Persistent data storage



\## Technologies Used



\- Python

\- SQLite



\## Project Structure

```bash
TimeTrakker/

│

├── database.py

```



\## Installation



Clone the repository:



```bash

git clone https://github.com/OmarAlabdAlla/TimeTrakker.git

cd TimeTrakker

```



Install dependencies:



```bash

pip install -r requirements.txt

```



Run the application:



```bash

python time\_tracker.py

```
